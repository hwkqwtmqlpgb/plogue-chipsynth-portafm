## Overview

chipsynth PortaFM models the Yamaha OPL3 FM chip from the Sound Blaster 16 and AWE32 era, reproducing four-operator FM patches, the OPL3 percussion mode, and stereo panning of the original hardware.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Plogue chipsynth PortaFM** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **OPL3 Emulation** | Four-operator FM voices with 18 channel polyphony matching hardware |
| **Percussion Mode** | Rhythm mode reproducing the five OPL3 drum voice channels |
| **OPL2 Compatibility** | Legacy OPL2 two-operator mode for FM patches from older games |
| **OPL Patch Import** | Load OPL instrument bank files in OPL2 and OPL3 formats |
